# Baysian_MRI_2023 摘要

[Wiley 全文](https://onlinelibrary.wiley.com/doi/10.1002/mrm.29624)；[PubMed 書目](https://pubmed.ncbi.nlm.nih.gov/36912453/)。

1. 研究目的：以擴散模型處理欠取樣 MRI 的多解問題，在重建影像時同步量化缺失 k-space 所致的不確定性。
2. 研究方法：以 RefineNet 分數式擴散模型學習複數腦影像先驗，結合多線圈量測模型與高斯似然，利用 Langevin MCMC 抽取後驗樣本；樣本平均形成 MMSE 重建，像素變異形成不確定性圖，並與 MAP、ℓ1-ESPIRiT 及 XPDNet 比較。
3. 主要結果：在 11.8% k-space 的代表性案例中，NET1 與 NET2 的 PSNR／SSIM 分別為 34.05 dB／0.9050 及 37.21 dB／0.9360；不確定性多集中於邊界、細節與可能錯誤區域。該示例中 MMSE 指標優於 MAP，擴散先驗較傳統方法保留更多細節，且可跨部分對比重用，但單切片重建約需 10 分鐘。
4. 結論：此框架可兼顧重建品質與條件式不確定性提示，但結果受先驗、量測模型及抽樣品質限制；不確定性並非疾病機率，臨床效益仍待驗證。

關鍵字：貝氏 MRI 重建、擴散模型、欠取樣 k-space、後驗抽樣、MCMC、MMSE、不確定性估計。
