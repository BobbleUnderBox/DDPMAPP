THOR（Temporal Harmonization for Optimal Restoration）是一種利用擴散模型進行醫療影像異常偵測與定位的方法。核心想法是：**先學習健康組織的外觀，再把待檢查影像重建成「假想健康版本」，透過兩者差異找出可疑區域。** 它特別處理一個問題：修復病灶時，如何保留病人原本正常的解剖結構，減少正常組織被誤判為異常的情況。[原始論文](https://arxiv.org/html/2403.08464v1)

**輸入**是一張經前處理的二維灰階醫療影像。官方提供腦部 T1 加權 MRI 軸向切片與兒童腕部 X 光的不同權重，預設尺寸為 128×128，因此應依影像部位與模態選擇對應模型。推論時只需待檢查影像，不必先提供病灶標註、文字提示或同一位病人的健康影像；腦部三維掃描則需按切片處理。[官方說明](https://github.com/ci-ber/THOR_DDPM#setup-and-run)、[模型設定](https://github.com/ci-ber/THOR_DDPM/blob/main/projects/thor/configs/brain/thor.yaml)

**輸出**包括假想健康重建影像，以及每個像素的異常分數圖。重建影像呈現模型認為較符合健康分布的外觀；異常圖則呈現原圖與重建的偏離程度，可用熱圖疊加顯示。設定門檻後，可進一步轉成二值異常遮罩，標出疑似病灶範圍。官方程式也會彙整整張影像的異常分數，但這些分數表示偏離程度，不能直接解讀成某種疾病的罹患機率。[輸出實作](https://github.com/ci-ber/THOR_DDPM/blob/main/model_zoo/ddpm.py)、[遮罩評估](https://github.com/ci-ber/THOR_DDPM/blob/main/projects/thor/DownstreamEvaluatorAtlas.py)

**模型內部**以 DDPM 與 U-Net 去噪網路為基礎。訓練時，系統對健康影像加入不同程度的雜訊，讓網路根據帶雜訊影像及目前步驟，學習預測加入的雜訊。反覆練習後，模型便學到如何逐步恢復健康影像的結構與紋理。每一步的網路輸出是雜訊估計，系統再利用它更新影像；最終重建與異常圖由整個流程產生。這種學習方式不需要逐一標出各種疾病，病灶定位來自後續重建差異。[訓練實作](https://github.com/ci-ber/THOR_DDPM/blob/main/projects/thor/DDPMTrainer.py)、[模型實作](https://github.com/ci-ber/THOR_DDPM/blob/main/model_zoo/ddpm.py)

推論時，THOR 先把輸入影像加噪到指定程度，再逐步去噪，嘗試將可疑結構恢復為學到的健康外觀。雜訊太少，模型可能保留病灶；雜訊太多，又可能連正常細節一起改變。THOR 的主要設計是在去噪途中加入引導，利用原圖資訊持續修正重建方向；這項機制作用於推論階段，既有的相容 DDPM 不必為此重新訓練。[方法說明](https://arxiv.org/html/2403.08464v1#S3)

具體而言，在選定的去噪步驟，模型先估計當下的乾淨影像，再與原圖比較。比較同時考慮像素亮度差異，以及 LPIPS 所衡量的影像特徵差異，形成暫時的異常圖。經正規化與區域擴張等處理後，**疑似異常處較多採用模型重建，疑似正常處則較多保留原圖**。融合影像再加回對應程度的雜訊，繼續去噪，讓病灶修復與正常結構保留在同一流程中反覆協調。[引導流程實作](https://github.com/ci-ber/THOR_DDPM/blob/main/model_zoo/ddpm.py)

這就是名稱中的「時間調和」：時間指同一次推論的擴散步驟。最後再以調和平均整合多個步驟的異常圖。直觀而言，這種整合較重視在多個階段都持續呈現差異的位置，降低單一步驟偶然產生高分的影響。因此，最後的異常圖包含多個重建階段的資訊。[方法說明](https://arxiv.org/html/2403.08464v1#S3)

**用途**上，THOR 適合研究缺少大量病灶標註時的異常定位；論文驗證涵蓋腦部缺血性中風病灶，以及兒童腕部骨折、異物、金屬植入物等異常。若用於本專案展示，可並列原圖、重建圖、熱圖與門檻化遮罩，讓使用者理解模型修改了哪些地方。不過，假想健康影像只是模型估計；石膏、姿勢差異等也可能造成高分，低解析度則可能漏掉細微變化，判讀時仍須區分影像差異與真正病灶。[實驗與限制](https://arxiv.org/html/2403.08464v1#S4)
