cDAL 是結合**條件式擴散、空間注意力與隨機潛在嵌入**的監督式醫療影像分割模型。它以醫療影像提供解剖結構線索，從隨機雜訊逐步生成分割遮罩，並利用判別器輔助訓練，讓模型在少量去噪步驟內學習目標輪廓。不同任務分別訓練，使用對應權重。[官方介紹](https://github.com/Hejrati/cDAL)

輸入方面，MoNuSeg 使用彩色病理切片，胸腔 X 光使用灰階影像，海馬迴任務使用 T1 加權 MRI。訓練需要影像與逐像素的正確標註；推論只需影像。文件中的「3D hippocampus」指三維資料集，**原論文模型實際逐張處理二維切片**，並未直接建模整個三維體積。[論文資料與限制](https://arxiv.org/html/2502.06997v1#S3.SS6)

官方設定將病理與胸腔 X 光影像處理為 256×256，海馬迴切片為 32×32。每一步生成器接收四項資訊：醫療影像 \(I\)、當前含噪遮罩 \(x_t\)、時間步 \(t\)，以及隨機潛在向量 \(z\)。影像與遮罩先經各自的特徵編碼，再以特徵相加融合。主幹採 U-Net 類型架構，利用殘差區塊、下採樣、上採樣及跳接，整合局部邊界與整體形狀；時間嵌入則告訴網路目前的噪聲階段。[生成器實作](https://github.com/Hejrati/cDAL/blob/master/score_sde/models/ncsnpp_generator_adagn.py)、[海馬迴處理](https://github.com/Hejrati/cDAL/blob/master/train_cDAL_hippo.py)

輸出方面，模型先產生與處理後切片空間對齊的連續數值分割圖，再轉成類別遮罩。肺野與細胞核任務區分前景、背景；海馬迴區分背景、前部與後部。細胞核輸出屬於二元語意分割，不會自動替每個細胞核編號。論文對同一影像生成五次並取平均，以降低單次隨機採樣造成的波動。[論文輸出方式](https://arxiv.org/html/2502.06997v1#S3.SS2)、[二類分割評估](https://github.com/Hejrati/cDAL/blob/master/metrics.py)

擴散機制的核心是對**標註遮罩加噪**，醫療影像持續提供固定的條件資訊。訓練時，正向擴散把乾淨遮罩逐步擾亂；生成器根據含噪遮罩與影像條件，直接估計乾淨遮罩。接著，利用這個估計值與當前含噪狀態，透過擴散後驗分布抽樣出下一個噪聲較少的遮罩。推論由純高斯雜訊開始，重複此程序，直到形成最後的分割結果。[採樣實作](https://github.com/Hejrati/cDAL/blob/master/sampling_monu_and_lung.py)

判別器是帶有時間條件的卷積網路，學習區分由真實標註加噪得到的遮罩，以及由生成結果得到的遮罩；判別時也參考相鄰時間步的含噪狀態。實作使用共享判別器並輸入時間步，處理不同噪聲程度。判別器更新時學習真偽分類；生成器更新時，則以預測遮罩與正確標註之間的均方誤差作為訓練目標。[訓練實作](https://github.com/Hejrati/cDAL/blob/master/train_cDal_monu_and_lung.py)

空間注意力來自判別器中間層的特徵：先對通道取平均，再放大至標註大小，與正確遮罩逐像素相乘，接著加噪後送入生成器。這讓生成器重建時更重視具有辨識力的空間區域。注意力透過訓練輸入的處理方式發揮作用，**正式推論會移除判別器**。[注意力訓練與推論流程](https://github.com/Hejrati/cDAL/blob/master/train_cDal_monu_and_lung.py)

隨機潛在向量 \(z\) 先經正規化與多層感知器映射，再注入編碼器、中間層及解碼器的殘差區塊；每個去噪步驟重新抽取向量。作者藉此表達更複雜、多峰的去噪分布，支援一次跨越較大的噪聲差距。論文中的 MoNuSeg 使用四步，肺野與海馬迴使用兩步；若生成五次取平均，仍需完成五輪採樣。官方海馬迴訓練碼預設則為四步，實際執行須核對權重搭配的設定。[論文機制與步數](https://arxiv.org/html/2502.06997v1#S2.SS3)、[海馬迴設定](https://github.com/Hejrati/cDAL/blob/master/train_cDAL_hippo.py)
