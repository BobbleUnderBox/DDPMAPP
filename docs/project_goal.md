# 專案最終目標

本文件記錄專案的最終產品目標與完整架構；

## 使用者情境

使用者在使用此專案提供的 diffusion model 時，能夠了解模型依據什麼判斷病灶分割或異常區域，以及模型的能力限制。

## 專案功能

提供多種可解釋性工具。醫療人員選擇此專案提供的模型與待解釋影像後，系統根據使用者想要解釋的方向，提供固定流程，引導使用者完成操作。

流程結束後，生成可解釋性報表，包含判讀問題、原始輸入與模型結果、採用方法與原因、圖表及閱讀說明、分析限制、使用者註記，以及模型版本與執行設定。尚未完成的操作提供暫存點，供後續繼續執行。

模型與工具的規劃及實作進度分別維護於 [model_list](model/model_list.md) 與 [xtool_list](xtool/xtool_list.md)。系統依模型能力與工具需求檢查相容性，再允許執行。
